## ✨ Sobre o Projeto

Este é um projeto **criado por [ALLAN VINICIUS SELEGUIM](https://github.com/allandevbrazil)** para o **portfólio**, com o intuito de demonstrar **skills de frontend** 🎨.

O site é uma experiência **cinematográfica** inspirada no Homem de Ferro 🦾, com:

- 🎬 **Animação cinematográfica** com sequência de frames
- 🔊 **Música ambiente** estilo cyberpunk
- 🖥️ **HUD futurista** com interface de sistema
- 🎨 **Design cyberpunk** com efeitos neon e glitch
- 📱 **Totalmente responsivo**
- ⚡ **Animações suaves** com Framer Motion
- 🚀 **Deploy automático** no GitHub Pages

## 🚀 Como Rodar Localmente

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/allandevbrazil/ironman.git
cd ironman
```

### 2️⃣ Instalar as dependências

```bash
npm install
```

### 3️⃣ Rodar o servidor de desenvolvimento

```bash
npm run dev
```

### 4️⃣ Abrir no navegador

Acesse [http://localhost:3000](http://localhost:3000) 🎉

---

## 🏗️ Build de Produção

```bash
npm run build
```

Para rodar a versão de produção localmente:

```bash
npm start
```
